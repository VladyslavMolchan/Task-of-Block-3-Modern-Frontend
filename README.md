# Книга Менеджер (Book Manager)

Цей проект є простим веб-додатком для керування бібліотекою книг. Ви можете переглядати список книг, додавати нові, редагувати існуючі та видаляти їх. Додаток побудований на **React** з використанням **Material-UI** та кастомних компонентів для створення інтерфейсу.

## Опис Функціоналу

### Список Книг
- **Перегляд**: Список усіх книг з можливістю переглядати їх деталі.
- **Фільтрація**: Можливість фільтрувати книги за назвою, автором або роком публікації.
- **Пагінація**: Завдяки пагінації, список книг розбивається на сторінки, щоб полегшити навігацію.

### Деталі Книги
- **Перегляд**: Перегляд детальної інформації про книгу, включаючи назву, автора та рік публікації.
- **Редагування**: Можливість редагувати інформацію про книгу (для вже існуючих записів).
- **Створення**: Можливість створити нову книгу.
- **Видалення**: Можливість видаляти книгу з бібліотеки.

### Сповіщення
Під час виконання  редагування, видалення) відображаються сповіщення для інформування користувача про успішний результат або помилку.

## Структура Проекту

Проект складається з кількох основних компонентів:

1. **`BooksList`** - Компонент, що відображає список книг, з можливістю фільтрації та пагінації.
2. **`BookDetails`** - Компонент для перегляду та редагування деталей конкретної книги.
3. **`BookForm`** - Формуляр для введення даних книги (назва, автор, рік публікації).
4. **`DeleteDialog`** - Модальне вікно для підтвердження видалення книги.
5. **`Notification`** - Сповіщення про результат операцій (успіх або помилка).
6. **`Pagination`** - Компонент пагінації для зручного перегляду сторінок.
7. **`Filters`** - Фільтри для пошуку книг за певними критеріями.

## Запуск Проекту

1. Перейти https://github.com/VladyslavMolchan/Tasks-of-Module-2-Spring-Boot-and-REST-API та прочитати Readme, запустити бекенд частину.
2. Головне завантажити книги через POST  upload, книги знаходяться у файлі upload.json це можна зробити через swagger http://localhost:8080/swagger-ui/index.html, http://localhost:8080/api/books/_upload 
Треба завантажити книги в базу.
3. Встановлюємо залежності npm install
3. Запускаємо фронтенд частину та насолоджуємось.
5. npm start або yarn start
